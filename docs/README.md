# Contributor documentation

Start with [architecture](architecture.md), then read the guide relevant to your change:

- [Errors](errors.md): typed errors, public responses, and diagnostics.
- [Runtime](runtime.md): database ownership, background delivery, and public forms.
- [Terminology](terminology.md): product and code names.

[AGENTS.md](../AGENTS.md) contains contribution rules. The [root README](../README.md) covers setup, checks, and deployment. Schemas, configured lint, and tests are the source of truth for implementation details; keep these guides in sync when behavior changes.
